## Introduction

The **Nyamira EDAMS Mobile Application** is a comprehensive digital platform designed for Nyamira County's Electronic Development Application Management System. This mobile app enables citizens, developers, and stakeholders to efficiently manage development applications, track permits, make payments, and access land information on-the-go.

### Key Benefits
- **Streamlined Process**: Submit and track applications digitally
- **Real-time Updates**: Get instant notifications on application status
- **Secure Access**: Enterprise-grade security for your data
- **Mobile Convenience**: Access all features from your smartphone
- **Document Management**: Upload and manage required documents easily

## Getting Started

### System Requirements
- **Android**: Version 5.0 (API level 21) or higher
- **iOS**: Version 12.0 or higher
- **Internet Connection**: Required for most features
- **Storage**: At least 100MB free space

### Installation
1. Download the app from the official app store
2. Install the application on your device
3. Launch the app and follow the setup process

When you first open the app, you'll see:
- **Welcome Screen**: Introduction to EDAMS features
- **Feature Carousel**: Overview of app capabilities
- **Get Started Button**: Begin your journey
- **Learn More Button**: Access help and information

## Step-by-Step Instructions

### 1. Account Setup

#### Registration
1. Open the app
2. Tap "Get Started"
3. Select "Register" or "Sign Up"
4. Fill in required information:
   - Full Name
   - Email Address
   - Phone Number
   - Password (minimum 8 characters)
   - Confirm Password
5. Accept terms and conditions
6. Tap "Create Account"
7. Verify your email (if required)

#### Login
1. Open the app
2. Enter your email address
3. Enter your password
4. Tap "Login"
5. Wait for authentication

### 2. Using the Dashboard

#### Home Screen Overview
The home screen displays:
- **Welcome Message**: Personalized greeting
- **User Role**: Your account type (Citizen, Developer, etc.)
- **Quick Actions**: Fast access to common tasks
- **Recent Activity**: Latest updates and notifications

#### Quick Actions Available
- **Report Illegal Developments**: Report unauthorized construction
- **Site Visits**: Schedule and manage site inspections
- **New Application**: Start a new permit application
- **View Map**: Access land parcel information

### 3. Managing Applications

#### Creating a New Application
1. From the home screen, tap "New Application"
2. Select application type:
   - Building Permit
   - Development Permit
   - Change of Use
   - Subdivision Permit
   - Renewal Application
3. Fill in application details:
   - Project description
   - Location information
   - Contact details
   - Project timeline
4. Upload required documents:
   - Tap "Add Document"
   - Choose "Camera" or "Gallery"
   - Take photo or select file
   - Add document description
5. Review all information
6. Tap "Submit Application"
7. Note your application reference number

#### Tracking Applications
1. Go to "Applications" tab
2. View list of your applications
3. Tap on any application to see details
4. Check status updates:
   - **Pending**: Awaiting review
   - **Under Review**: Being processed
   - **Approved**: Application approved
   - **Rejected**: Application denied
   - **Completed**: Process finished
5. View comments and requirements
6. Upload additional documents if requested

### 4. Payment Management

#### Viewing Payments
1. Go to "Payments" tab
2. See list of all invoices and payments
3. Filter by status:
   - Pending payments
   - Completed payments
   - Overdue payments
4. Tap on any payment for details

#### Making Payments
1. Find the payment you want to make
2. Tap "Pay Now"
3. Select payment method:
   - Mobile Money (M-Pesa, Airtel Money)
   - Bank Transfer
   - Credit/Debit Card
4. Enter payment details
5. Confirm payment
6. Wait for confirmation
7. Save payment receipt

### 5. Profile Management

#### Updating Personal Information
1. Go to "Profile" tab
2. Tap "Personal Information"
3. Edit your details:
   - Name
   - Email
   - Phone number
   - Address
   - Professional information
4. Tap "Save Changes"

#### Changing Password
1. Go to "Profile" tab
2. Tap "Change Password"
3. Enter current password
4. Enter new password
5. Confirm new password
6. Tap "Update Password"

### 6. Reporting Illegal Developments

#### Creating a Report
1. From home screen, tap "Report Illegal Developments"
2. Fill in report details:
   - Location of illegal development
   - Description of the issue
   - Your contact information
3. Take photos as evidence:
   - Tap camera icon
   - Take multiple photos from different angles
   - Add photo descriptions
4. Submit the report
5. Note your report reference number

### 7. Site Visits

#### Scheduling a Site Visit
1. From home screen, tap "Site Visits"
2. Tap "Schedule New Visit"
3. Select application (if applicable)
4. Choose preferred date and time
5. Add visit notes or requirements
6. Submit request
7. Wait for confirmation

#### Managing Site Visits
1. Go to "Site Visits" from home screen
2. View list of scheduled visits
3. Check visit status and details
4. Add notes or updates
5. Upload visit photos if required

## Troubleshooting

### Common Issues and Solutions

#### App Won't Open
- **Problem**: App crashes on startup
- **Solution**: 
  - Restart your device
  - Clear app cache
  - Reinstall the app
  - Check device storage space

#### Login Problems
- **Problem**: Cannot log in
- **Solution**:
  - Check internet connection
  - Verify email and password
  - Try "Forgot Password" option
  - Contact support if issue persists

#### Document Upload Issues
- **Problem**: Cannot upload documents
- **Solution**:
  - Check file size (should be under 10MB)
  - Ensure file format is supported (PDF, DOC, JPG, PNG)
  - Check internet connection
  - Try taking a new photo

#### Payment Problems
- **Problem**: Payment not processing
- **Solution**:
  - Check internet connection
  - Verify payment details
  - Try different payment method
  - Contact your bank if using card

#### Map Not Loading
- **Problem**: Map features not working
- **Solution**:
  - Enable location services
  - Check internet connection
  - Update app to latest version
  - Restart the app

### Error Messages

#### "Network Error"
- Check your internet connection
- Try again in a few minutes
- Contact support if problem persists

#### "Invalid Credentials"
- Double-check your email and password
- Use "Forgot Password" to reset
- Contact support for account issues

#### "File Too Large"
- Compress your image or document
- Use a different file format
- Split large documents into smaller parts

#### "Session Expired"
- Log out and log back in
- Clear app data and restart
- Contact support if issue continues
